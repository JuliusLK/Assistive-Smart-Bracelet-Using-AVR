# Enclosure

| File | Description |
|------|-------------|
| [`Casing.stl`](Casing.stl) | Prototype enclosure (STL mesh, ready for slicing) |

## Dimensions
Approximate bounding box (assuming the model is in millimeters): **89 x 74 x 43 mm**.

This is a prototype enclosure that holds the Arduino Nano, sensor modules, OLED, and battery. A smaller, wrist-sized enclosure is part of the [roadmap](../../README.md#roadmap).

## Printing notes
- Material: **PLA**
- Supports: **not needed**

## Component placement
The positions of the OLED and the sensors were decided during PCB layout, so that the whole assembly fits inside the casing.

## Source files
STL is an export format and is hard to edit. If you have the original CAD file (e.g. `.f3d`, `.step`), add it to this folder too.

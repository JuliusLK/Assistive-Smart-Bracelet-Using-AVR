# Hardware

- `schematic/`: circuit schematic (made in EasyEDA). Add the EasyEDA source file (.json / .epro) here too if available.
- `enclosure/`: 3D enclosure design (`Casing.stl`) and notes. See [`enclosure/README.md`](enclosure/README.md).
- `bom.csv`: bill of materials.

Recommended hardware license: CERN-OHL or CC BY-SA 4.0.
